# HeyAGI

> 探索人工智能的无限可能，迎接 AGI 时代

HeyAGI 是一个专注于人工智能技巧分享与 AGI 发展展望的开源项目。我们致力于收集和分享 AI 领域的实用技巧、学习资源和前沿动态。

## ✨ 项目特色

- **实用技巧**：分享 AI 使用技巧和最佳实践
- **学习资源**：推荐优质的学习资料和教程
- **前沿追踪**：关注 AI 和 AGI 领域的最新进展
- **思考探讨**：记录对通用人工智能的期待与思考
